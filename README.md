# github-achievements-lab

Repo latihan untuk mempelajari cara kerja **GitHub Achievements** lewat `gh` CLI + `git`.

## Struktur

```
.
├── README.md          # file ini
├── ACHIEVEMENTS.md     # panduan langkah demi langkah tiap achievement
├── docs/
│   └── log.md          # file target untuk PR-PR kecil (Pull Shark)
├── src/
│   └── hello.md        # file contoh
└── scripts/
    └── pull-shark.sh   # otomasi bikin + merge banyak PR kecil
```

## Target achievement (urut termudah)

| # | Achievement          | Syarat inti                                                        |
|---|----------------------|-------------------------------------------------------------------|
| 1 | Quickdraw            | Tutup 1 issue/PR dalam < 5 menit sejak dibuat                      |
| 2 | YOLO                 | Merge 1 PR tanpa review                                            |
| 3 | Pull Shark           | Merge PR (tier: 2 / 16 / 128 / 1024)                               |
| 4 | Pair Extraordinaire  | PR ter-merge dengan commit `Co-authored-by:` akun lain             |
| 5 | Galaxy Brain         | Jawaban kamu di Discussion ditandai sebagai answer (tier: 2/8/16/32) |

Detail perintah ada di [ACHIEVEMENTS.md](ACHIEVEMENTS.md).
